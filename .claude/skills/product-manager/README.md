# ai-agent-product-manager

产品经理 Agent Skill — 产品规划、需求分析、用户研究、路线图制定、竞品分析。

跨 50+ 运行时兼容（Claude Code / Cursor / Codex CLI / Gemini CLI / Windsurf）。

## 安装

```bash
skills install peterfei/ai-agent-product-manager
```

或手动将 `SKILL.md` 中的运行时配置片段复制到对应工具。

## 能力

- 需求分析与优先级排序
- 用户研究与竞品分析
- 产品路线图规划
- 跨角色沟通与需求传达
