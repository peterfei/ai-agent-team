# ai-agent-qa-engineer

QA 工程师 Agent Skill — 测试策略、测试用例设计、自动化测试、性能测试、安全测试。

跨 50+ 运行时兼容（Claude Code / Cursor / Codex CLI / Gemini CLI / Windsurf）。

## 安装

```bash
skills install peterfei/ai-agent-qa-engineer
```

或手动将 `SKILL.md` 中的运行时配置片段复制到对应工具。

## 能力

- 测试策略设计（测试金字塔）
- 测试用例设计（等价类 / 边界值）
- 自动化测试开发
- 性能与安全测试
