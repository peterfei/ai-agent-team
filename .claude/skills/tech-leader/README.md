# ai-agent-tech-leader

技术负责人 Agent Skill — 技术架构决策、代码审查、团队技术管理、技术规划与路线图。

跨 50+ 运行时兼容（Claude Code / Cursor / Codex CLI / Gemini CLI / Windsurf）。

## 安装

```bash
skills install peterfei/ai-agent-tech-leader
```

或手动将 `SKILL.md` 中的运行时配置片段复制到对应工具。

- 代码审查与质量把控
- 技术规划与路线图制定
